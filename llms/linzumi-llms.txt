# Linzumi

> Team chat that runs a fleet of AI coding agents inside every channel. Engineering teams kick off work, watch agents in real time, review output, and ship code from the thread. Agents run on the developer's own machine via a local Commander runner, not in a sandboxed cloud VM. Y Combinator Spring 2026, San Francisco.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from public sources.
Linzumi serves its own /llms.txt, but as of this date it is an uncustomized site-template
placeholder that does not describe Linzumi, so this accurate replacement was generated instead.

Linzumi publishes no developer API program, documentation portal, or OpenAPI definition.
The product API at serve.linzumi.com is private; what is public is the first-party CLI.

## Developer surface

- [@linzumi/cli on npm](https://www.npmjs.com/package/@linzumi/cli): The only published first-party package. Installs the local Commander runner, authenticates the machine, registers trusted folders, starts Codex sessions, and hosts the local MCP server. MIT licensed, Node >=20.

Quick start:

```bash
npx -y @linzumi/cli@latest signup
linzumi paths add ~/code/my-app
linzumi start ~/code/my-app
```

## MCP

Linzumi ships a first-party local MCP server named `linzumi`, bundled with the CLI and preconfigured
for Commander-started Codex sessions. Other MCP-compatible agents configure it manually:

```bash
linzumi mcp config --api-url https://serve.linzumi.com --format codex
linzumi mcp config --api-url https://serve.linzumi.com --format claude-code
linzumi mcp server --api-url https://serve.linzumi.com
```

Tools: `linzumi_get_message`, `linzumi_get_thread`, `linzumi_get_channel`, `linzumi_dm_owner`.

## Authentication

- Default: browser loopback OAuth callback on the runner machine.
- Headless: device-code flow via `linzumi connect --auth-mode device`, approving an 8-character code at https://serve.linzumi.com/api/v2/local-codex-runner/device (expires in 10 minutes).

## Safety model

- Agents edit only inside explicitly trusted folders listed in `~/.linzumi/config.json`.
- Git safety snapshots are taken before each agent turn and are restorable via `linzumi safety-snapshots restore`.
